# Experiment 6 - Responsive Blog Website

A blog website made with Bootstrap 5 and media queries for Web Development Lab (Week 6).

## Bootstrap features used
- Navbar that collapses into a menu button on small screens
- Grid system: 1 column of posts on phones, 2 columns on tablets, and a sidebar next to the posts on large screens
- Cards for blog posts and the sidebar
- Form classes and buttons

## Media queries (in style.css)
- `max-width: 768px` - smaller header and banners for tablets
- `max-width: 576px` - even smaller text and centered headings for phones
- `min-width: 1200px` - bigger header for large screens

## How to test
Open the page and press F12, then click the device icon (or press Ctrl+Shift+M) and change the screen size.

## Files
- `index.html` - the blog page
- `style.css` - my CSS and media queries
